01

Executive Summary & Core Differentiators

Traditional dubbing systems fail catastrophically when applied to children’s animation. Off-the-shelf voice cloning and text-to-speech platforms flatten expressive characters into a generic narrator, rely on literal machine translations that lack kid-friendly nuance, and ignore strict cultural taboos across Asian-Pacific (JAPAC) markets.

XIVI (ToonLingo) re-architects localization as an agentic collaborative pipeline where specialized Google Gemini agents assume distinct editorial responsibilities:

🎭

Series-Wide Voice Consistency

Character voices are never generated randomly per episode. Voices are mapped to persistent character_id profiles in PostgreSQL, backed by Gemini 3.8 Flash Voice Design and native audio prebuilt voices.

🌏

Contextual Kids Localization

Dialogue avoids clumsy, literal machine translation. Specialized prompts instruct Gemini to adapt humor, child-friendly idioms, and natural conversational cadence appropriate for young audiences in target languages.

🛡️

Market Cultural Guardrails

Checks dialogue against dynamic, database-backed cultural safety rules (Vietnam, Indonesia, Japan, etc.), generating natural language rationale and severity scores for human reviewers.

📚

Bilingual Learning & Quizzes

Agent 7 extracts age-appropriate vocabulary flashcards and interactive multiple-choice comprehension quizzes directly from dubbed dialogue for educational dual-purpose.

🎬

In-Browser Timeline Editor

Canva-style multi-track waveform editor in the browser allows fine-grained dialogue re-timing, clip trimming, volume adjustments, and server-side FFmpeg remuxing.

⚡

Script-First Parallel Workflow

Enables dubbing and translation to start immediately from locked scripts using AI duration benchmarks, unlocking parallel localization before finished video footage exists.

💡
Mandatory Human Review Gate: In strict adherence to our safety constitution, no AI agent is permitted to auto-publish content destined for young audiences. The studio dashboard requires explicit creator approval before finalized media is released.

Why Decouple API and Worker into 2 Cloud Run Services?

1. Response Latency vs Execution Duration: api must scale rapidly with user traffic, issuing signed upload URLs and metadata queries in under 50ms. worker processes entire video dubs and FFmpeg muxing jobs that take several minutes.

2. Resource Sizing & Cost Efficiency: The API runs on a lightweight db-f1-micro equivalent tier scaling to zero. The worker requires 2 vCPU and 2GiB of RAM with concurrency=1 to prevent FFmpeg out-of-memory errors during high-resolution audio/video remuxing.

3. Cloud Pub/Sub Asynchronous Decoupling: The API enqueues tasks by publishing to agent-events and immediately returns 202 Accepted. The worker receives push events authenticated via Google IAM OIDC tokens.

The 7-Stage Agent Pipeline

Every pipeline agent inherits from a unified abstract interface: Agent.run(context: PipelineContext) -> PipelineContext (defined in backend/worker/agents/base.py). This strict separation guarantees that agents can be independently audited, tested, and updated.

1

Ingestion & Diarization Agent gemini-3.6-flash

Probes video audio track duration with FFprobe, extracts dialogue lines, assigns sub-second timestamps, and performs multi-speaker acoustic diarization without relying on external Whisper services.

Multimodal Audio
2

Voice Profiling & Character Registry Agent gemini-3.8-flash-tts

Acoustically profiles character timbre and pitch. Matches against prior project character records or synthesizes novel voices via Gemini 3.8 Flash Voice Design with 3-tier safety fallback.

Voice Design
3

Translation & Localization Agent gemini-3.6-flash

Translates dialogue with age-appropriate JAPAC localization, preserving character personality, child-friendly humor, and natural conversational cadence tailored for young audiences.

Contextual NLP
4

Cultural Safety & Moderation Agent gemini-3.6-flash

Queries country-specific rules stored in PostgreSQL (cultural_safety_rules). Flags sensitive taboos (religious, diet, gesture, historical) with severity ratings and explanatory rationales.

Human In Loop
5

Dubbing & Native Audio Synthesis Agent gemini-3.1-flash-tts-preview

Generates high-frequency native speech for each line. Automatically applies pitch adjustments and audio stretch/compression to guarantee alignment within dialogue time windows.

Native TTS
6

Audio-Video Multiplexing Service FFmpeg C Engine

Splits source audio into background accompaniment and dialogue. Replaces the dialogue track with dubbed clips, normalizes volume, and encodes with faststart moov atoms for instant seeking.

Mux Service
7

Educational Content & Quiz Generator gemini-3.6-flash

Runs asynchronously outside the critical video path. Generates 8-12 bilingual vocabulary flashcards and interactive multiple-choice quiz questions for dual-purpose learning.

Key Timeline Editor Features

  • Sub-100ms Client Response: Drag-and-drop repositioning, clip boundary trimming, and volume balancing respond instantaneously via local Zustand state.
  • Waveform Rendering: Integrated WaveSurfer.js generates visual audio waveforms for each dialogue line, allowing creators to align speech visually with on-screen character lip movement.

  • Non-Destructive Server-Side Export: Clicking "Export Video" calls EditorExportService, which compiles an FFmpeg filter_complex script that mixes audio gains, offsets, and cuts into a pristine new MP4 file.

Script-First Ingestion Workflow (Spec 003)

In standard dubbing tools, jobs cannot begin until the final video is edited and uploaded. In children's animation studios, scripts are locked weeks before animation is rendered. XIVI introduces the Script-First Workflow, allowing localization to run in parallel with visual production.

Feature Video-First Workflow (Spec 001) Script-First Workflow (Spec 003)
Starting Input Recorded source MP4 video file Locked CSV or plaintext script
Initial Agent IngestionAgent (Gemini Audio Diarization) ScriptBenchmarkAgent (Duration Benchmark)
Speech Timing Source Measured directly from original actors AI-generated English benchmark audio duration
Video Dependency Required immediately at job creation Attached later via POST /jobs/{id}/attach-video
Studio Turnaround Sequential (Video must finish before dubbing) Parallel: Dubbing finishes at the same time as video editing
⚡
Late Video Attachment: When the final animation cut is completed, the creator calls POST /jobs/{id}/attach-video. The system maps the pre-dubbed audio lines directly to the video timeline, running only the final FFmpeg muxing step without repeating any Gemini translation or dubbing calls.

Fault-Tolerant Checkpoint & Resume Guarantee

Cloud Run containers can be preempted or shut down at any moment. To guarantee that long-running dubbing jobs never lose expensive progress, the worker executes a transactional checkpoint to the jobs.current_stage column in Cloud SQL before updating Firestore.

If a container crashes or times out during stage 5 (Dubbing), the next delivery of the Pub/Sub message inspects current_stage = "safety_checked" and immediately resumes dubbing — avoiding redundant Gemini API calls and eliminating double charges.

Google Gemini Integration & Model Selection

Every call to Google Gemini is centralized within a singleton service: backend/worker/services/gemini_client.py. Agents are strictly prohibited from importing google.genai directly, ensuring consistent rate limiting, caching, and retry policies.

Model Identifier Primary Function Engineering Selection Rationale
gemini-3.6-flash Transcription, Translation, Cultural Safety, Educational Content Verified empirically against v1beta REST endpoints. Low latency, large multimodal context, and native JSON structured output compliance.
gemini-3.1-flash-tts-preview High-frequency dialogue TTS audio generation Native audio model offering rapid waveform generation with prebuilt voices (Aoede, Puck, Charon, Fenrir, Kore). Not restricted by low daily quotas.
gemini-3.8-flash-tts Voice Design (Voice Synthesis from Text Description) Used exclusively via client.voices.create(type="prompted") to design novel character voices without requiring voice owner consent recordings.

3-Tier Fallback Hierarchy for Character Voice Synthesis

When a character is identified, the system attempts voice assignment using three deliberate fallback layers (defined in build_voice_profile_metadata):

  1. Tier 1 — Gemini 3.8 Voice Design: Gemini evaluates the character’s personality description and synthesizes an entirely custom voice. If Google’s safety filter flags the generated voice (e.g. for sounding like a minor), the system gracefully catches the error and degrades to Tier 2.
  2. Tier 2 — Prebuilt Native Voice Match: Selects from Gemini's 12 prebuilt native voices matching the character's gender, pitch, and energy attributes.
  3. Tier 3 — Deterministic Hash Fallback: Applies hash(character_id) % 12, guaranteeing that the same character always speaks with a consistent voice across all episodes.

Cloud Firestore Realtime Reactive State

Cloud Firestore is utilized strictly for ephemeral realtime progress streaming to client browsers. Business transactional records remain safely isolated in PostgreSQL.

By leveraging Firestore's client-side onSnapshot listener in frontend/src/lib/firebase.ts, the studio dashboard receives live stage transitions, percentage increments, and error notifications without requiring a custom WebSocket cluster or long-polling loops.

Configuration Item Value Purpose
firestore.rules Role-based authentication check Restricts read access to verified project owners via Firebase Auth UID.
hosting.public frontend/dist Serves precompiled static assets directly from Firebase CDN edge caches.
hosting.rewrites ** -> /index.html Enables single-page application (SPA) client-side routing in React Router.

Test Isolation via SQLAlchemy Savepoint Transactions

The backend test suite comprises over 300 automated tests. To prevent test data pollution in development databases, backend/conftest.py opens an outermost database transaction and binds all session executions to nested savepoints (join_transaction_mode="create_savepoint"). Even when application code calls await session.commit(), rolling back the outermost fixture transaction completely wipes all test artifacts.

Technical Risks & Architectural Mitigations

Identified Risk Impact Implemented Architectural Mitigation
TIMEOUT Cloud Run 3600s execution limit on long animated episodes Episode chunking: split video into scenes, process chunks concurrently in the worker, and stitch final audio tracks at pipeline completion.
RATE LIMIT Gemini API quota exhaustion during peak batch jobs Redis key-value caching (TTL 24h) keyed by (text_hash, lang, mode) + exponential backoff retry up to 3 attempts.
DRIFT Audio and video synchronization drift during dubbing Timestamp preservation: dub clips are anchored to original transcribed sub-second boundaries rather than sequential concatenation.
CRASH Worker container preemption during FFmpeg muxing Granular checkpointing into jobs.current_stage before each stage transition, resuming exactly where execution paused.
